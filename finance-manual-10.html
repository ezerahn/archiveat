법인통장 이체·송금증 출력

법인통장에서 직접 이체하고, 입금확인증·자동이체 송금내역을 출력하는 순서입니다.

로그인·인증서·계좌 비밀번호·OTP는 이 문서에 두지 않습니다. 비밀번호 관리앱·OTP 기기에서 확인하세요.
💸 법인통장 직접 이체
전체계좌 → 이체 → OTP 이체실행
1

로그인 (공동인증서)

신한 기업뱅킹 → [공동인증서 로그인] → 이동식(E:) → 인증서 선택 → 암호 → [확인]
2

전체계좌 조회

로그인 후 [전체계좌 조회] 클릭
3

이체 버튼

원하는 계좌의 [이체] 버튼 클릭
4

거래·출금정보

이체구분(한 건씩·즉시 등) 선택 → 출금계좌 → 계좌 비밀번호 4자리
5

이체정보 입력

입금계좌(은행·번호) → 입금금액 → 거래메모(사무실 월세·기장료·급여 등 상세 필수) → [이체추가]
6

이체대기 → 다음

이체대기정보 확인 → [다음]
7

OTP 인증 → 이체실행

OTP 기기의 6자리 입력 → [이체실행]
🧾 입금확인증 출력
이체 완료 → 입금확인증 인쇄
1

입금확인증

이체 완료 화면에서 [입금확인증] 클릭
2

인쇄설정

바코드표시 체크 해제 → A4 1장당 매수 3매 → [보고서인쇄]
3

출력

미리보기에서 PRINT
🧾 자동이체 송금내역 출력
거래내역 → 상세거래내역 인쇄
1

계좌 조회

전체계좌에서 원하는 계좌 [조회]
2

항목 체크 → 보고서인쇄

거래내역에서 출력할 항목 체크 → [상세거래내역 보고서인쇄(건별)]
3

출력설정

잔액표시 체크 해제 → 3매 → [보고서인쇄]
4

출력

미리보기에서 PRINT

✅ 마무리 — 증빙 보관·전달

출력한 입금확인증·송금내역을 부가세 증빙 서철에 함께 보관·전달합니다. 거래메모(상세내역)를 꼭 기재해 두면 확인이 쉽습니다.

※ 이 매뉴얼은 따라 하는 절차서입니다. 기준·원리가 궁금할 땐 정산·신고 홈 → 세무 가이드를 보세요. 화면의 계좌·금액 등 민감정보는 가려진 상태로 넣었습니다.
