클래스 설계 가이드

클래스 홈의 구조·정산·콘텐츠 설계를 한 곳에 모았습니다.

개요

클래스는 보기형(B·박제형)입니다. 데이터는 엑셀 마스터가 원본이고, 화면은 보기 전용입니다.

기본 성격

항목내용
유형B (보기형·박제형). 케이터링(입력형)과 다름
데이터 원본class-master-all-v1.xlsx (회차·수강생 2시트)
화면 입력없음. 입력·수정은 채팅창 → 마스터 → gen으로 굽기
생성기gen_class.py (마스터 → class.html)
구역수익·사업

핵심 흐름

계산·검토(화면 도구) → 복사 → 채팅창 → 마스터 기록 → gen으로 굽기 → 보기 화면에 등장

상태 7단계

검토중 → 개요서 → 확정 → 모집중 → 개강/미달 → 수업완료 → 정산완료

마스터에 데이터가 들어온 순간(1층 카드 등장)부터 상태 관리 시작. A형(경기도지식)은 모집중 단계 없이 바로 확정.

화면 구성

케이터링과 동일한 3층 구조. 카드에서 자세히 보기를 누르면 6탭이 열립니다.

중요 판단(확정): 케이터링은 "등록(저장)"과 "빠른견적(계산만)"을 나눴지만, 클래스는 뭘 하든 마지막이 "복사 → 채팅창"으로 같으므로 계산기 하나로 통합. 복사하느냐 마느냐가 "등록이냐 테스트냐"를 가름.

정산

클래스는 3자 구조(고객·주최·우리·선생님). 부가세 항상 발생. 온/오프 원가 구조가 다름.

3자 구조 — 3개 숫자로 쪼갬

  • 총 수업료 = 기본가격(인당) × 인원
  • 주최 수수료 = %나 금액 (주최가 떼거나 / 우리가 줌)
  • 선생님 정산액 = 인당 1만원 / 수수료%
  • 우리 몫 = 총수업료 − 주최수수료 − 선생님정산액 (자동 계산)

온라인 vs 오프라인 — 원가 구조가 다름

온라인오프라인
재료우리가 준비·배송선생님이 준비
패킹·배송비있음 (고정)없음
정산 방식인당 1만원(강사비)수수료 % (기본 20%, 수정 가능)
계산식재료비+패킹+배송+강사비 → 수익률 판정판매가 × 수수료율 → 우리 몫

부가세

상품(용역 공급)이라 항상 발생. 인당 가격에 별도이기도, 포함이기도 함 → 선택 칸 필요.

예: 판매가 50,000 → 부가세 제외 45,455 (÷1.1)

경기도지식 정산 (실물 확정)

경기도지식(휴넷) → 우리: 키트비 150만원 (30명×5만, 강사료 포함) · 150만 전액 우리 매출 · 휴넷 앞 세금계산서 발행 · 지급: 휴넷 명의 · 수업월 익월 말일 우리 → 선생님: 인당 1만 × 30명 = 30만원 · 원천세 3.3%(9,900원) 원천징수 → 실지급 290,100원 우리 몫 = 150만 − 재료비 − 패킹 − 배송 − 선생님 30만

선생님 정산 방식 (원천세 / 세금계산서)

방식대상처리
원천세 (대다수)프리랜서·개인정산액에서 3.3% 원천징수 후 실지급. 뗀 세금 우리가 신고·납부
세금계산서 (간혹)사업자 선생님선생님이 계산서 발행 → 우리가 그 금액 입금 (원천징수 없음)

마스터에 회차별 선생님 유형(개인/사업자) 칸 필요.

콘텐츠 — 하나의 데이터, 여러 채널

내용(물)은 같고 그릇(양식)만 다름. 마스터에 공통 항목을 저장 → 채널별 양식에 꺼내 씀.

견적 계산기

3층 핵심 도구. 등록·견적·테스트 겸용. 계산 → 복사 → 채팅창 → 마스터 기록.

구성

  • 선택부: 발주처 · 온/오프라인 · 정산구조(A/B) · 정산방식(수수료%/인당1만) · 부가세(별도/포함)
  • 재료비 표: 빈 줄 15개 + "+행 추가". 구매처 링크(클릭 시 새 탭). 주문단위 수동 입력
  • 수익률 판정: 판매가·부가세·재료비·패킹·배송·강사비 → 수익률% + 20% 판정
  • 복사 버튼 📋: 결과를 텍스트로 클립보드 복사 → 채팅창 붙여넣기

1인 금액 자동 수식 (핵심)

1인금액 = (총금액 ÷ 인원) × (총필요량 ÷ 주문총량)

1000g 샀는데 500g만 쓰면 남은 500g은 원가 아님. 산 것 중 실제 쓴 비율만 인원으로 나눠야 정확 (소스류에서 차이 큼). 원본 시트 수식 =T5/$I$4*(O5/Q5)

수익률 판정 예 (경기도지식)

항목금액
판매가50,000
부가세 제외45,455 (÷1.1)
원가 합35,539 (재료 15,539 + 패킹 5,000 + 배송 5,000 + 강사 10,000)
수익9,916
수익률22% → 진행 가능 (기준 20% 이상)

복사 버튼이 채팅창에 자동 입력하는 건 브라우저 보안상 불가 → 복사 후 붙여넣기가 최선.

원칙

개인정보

  • html(github)에 안 넣는 것: 수강생 연락처·우편번호·주소·이름
  • html에 넣는 것: 회차 정보 + 인원 집계(숫자만)
  • 화면 "엑셀 마스터 받기" = 개인정보 뺀 공개용 class-master-open_날짜.xlsx
  • 완전판(연락처·주소·수식) = 채팅창에서 class-master-all-v1.xlsx

사진

  • 방식: 내장(base64) 금지 → 링크 방식(images/class/ 하위 폴더)
  • 파일명: class-[발주처영어]-[YYYYMMDD]-[종류].jpg (한글 금지·영어 소문자)
  • 예: images/class/class-gseek-20260622-main.jpg
  • 당장은 대표사진 1장. 후기는 초상권 보류.
