법인통장 입출금 확인

부가세 신고용 법인통장 거래내역을 은행에서 내려받아 삼화에 전달하는 순서입니다. 신한은행·우리은행 두 곳을 안내합니다.

로그인·인증서 정보(ID·PW·인증서 암호)는 이 문서에 두지 않습니다. 비밀번호 관리앱(또는 안전한 개인 메모)에서 확인하세요.
1분기 1~3월 2분기 4~6월 3분기 7~9월 4분기 10~12월
🏦 신한은행
기업인터넷뱅킹 → 전체계좌 조회 → 거래내역 엑셀 다운로드
1

기업뱅킹 로그인 (공동인증서)

신한은행 기업인터넷뱅킹에 접속해 [공동인증서 로그인]을 누릅니다.

저장매체 이동식(E:) 선택 → 인증서 선택 → 인증서 암호 입력 → [확인]
인증서 암호는 비밀번호 관리앱 참조
2

전체계좌 조회

로그인 후 첫 화면에서 [전체계좌 조회]를 클릭합니다.

3

계좌 선택 · 조회

전체계좌 목록에서 원하는 계좌의 [조회] 버튼을 클릭합니다.

4

조회 조건 설정

조회 조건을 맞추고 조회합니다.

과거거래순 선택 → 조회기간 해당 분기 → [조회]
5

엑셀 다운로드

거래내역 화면 오른쪽 위 엑셀 아이콘을 클릭해 다운로드합니다.

파일명에 "신한"을 붙여 보관
🏦 우리은행
기업뱅킹 로그인 → 계좌상세 → 거래내역조회 → 엑셀저장
1

기업뱅킹 로그인 진입

우리은행 기업 화면에서 [로그인] → [기업뱅킹]을 선택합니다.

2

공동인증서 로그인 선택

기업로그인 화면에서 [공동인증서 (구 공인인증서)]를 클릭합니다.

3

인증서 매체 선택

인증서 입력 창에서 [이동식디스크]를 누르고 USB DISK (E:)를 선택합니다.

4

인증서 선택 · 암호

인증서를 선택하고 인증서 암호를 입력한 뒤 [확인]을 누릅니다.

인증서 암호는 비밀번호 관리앱 참조
5

계좌현황 → 상세

입출금 계좌현황에서 원하는 계좌의 [상세]를 클릭합니다.

6

거래내역조회

계좌상세조회 창에서 [거래내역조회]를 클릭합니다.

7

조회 조건 설정

조회 조건을 맞추고 조회합니다.

조회기간 해당 분기 → 과거순 → [조회]
8

파일저장

거래내역 아래 [파일저장]을 클릭합니다.

9

엑셀저장

저장할 항목을 확인하고 [엑셀저장]을 누릅니다.

파일명에 "우리"를 붙여 보관

✅ 마무리 — 삼화에 전달

두 은행에서 내려받은 거래내역 엑셀을 삼화회계법인에 전달하면 법인통장 자료 준비 완료입니다. 통장 거래내역은 매출·매입 세금계산서와 대사(對査)하는 확인용 자료입니다.

※ 이 매뉴얼은 따라 하는 절차서입니다. 기준·원리가 궁금할 땐 정산·신고 홈 → 세무 가이드를 보세요. 화면은 계좌번호·잔액·식별정보가 가려진 상태로만 넣습니다.
