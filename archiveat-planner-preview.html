Archiveat Planner

콘텐츠 자산을 상품과 고객 제안으로 연결하는 매출 설계 시스템

아카이빗이 보유한 메뉴·레시피·사진·영상·클래스 운영 경험을 구조화하고, 이를 월별 상품, 고객 맞춤 클래스, 쿠킹박스, 케이터링 및 B2B 제안으로 전환하기 위한 프론트엔드 서비스 OS 제안서입니다.

콘텐츠 자산화메뉴 하나를 여러 상품과 채널로 재활용
제안 효율화고객 조건에 맞는 3·5·10개 후보 빠른 도출
매출 연결선택된 메뉴를 견적·과정개요서·운영안으로 구체화
01 · Overview

시스템의 성격과 목적

Archiveat Planner는 아카이빗의 콘텐츠 자산을 고객에게 적합한 상품과 제안으로 전환하여, 클래스·쿠킹박스·케이터링 매출을 높이기 위한 프론트엔드 서비스 OS입니다.

메뉴와 콘텐츠를 관리하는 데서 끝나지 않고, 고객 문의 분석 → 메뉴 큐레이션 → 상세 제안 → 수주까지 연결하는 시스템

03 · Theme Library

Annual Theme Library의 역할

분류 기준

아카이빗의 메뉴와 콘텐츠를 일관되게 분류합니다.

기획 기준

월별 상품, 캠페인, 몰 운영 및 콘텐츠 캘린더의 기준이 됩니다.

영업 기준

개별 메뉴가 아니라 의미 있는 묶음으로 기업과 기관에 제안합니다.

표현 예시
“이번 달은 오이소박이입니다”보다 “4월 봄김치 프로젝트 — 오이소박이·파김치·봄동겉절이·열무김치 중 선택”이 영업 관점에서 더 효과적입니다.

고객에게는 테마와 실제 메뉴를 함께 보여주되, Program·Project 같은 내부 관리 용어는 필요할 때만 노출합니다.

06 · Proposal System

고객 제안 구조

고객에게 처음부터 복잡한 프로그램 체계를 설명하지 않고, 고객 조건과 해당 월의 테마를 기준으로 실제 선택 가능한 메뉴 후보를 먼저 제안합니다.

1

고객 문의 입력

  • 진행 희망 월
  • 고객 유형
  • 참가 대상과 연령
  • 인원
  • 온라인·오프라인
  • 희망 수업시간
  • 행사 목적
  • 원하는 분위기
  • 선호 메뉴
  • 제외 식재료·알레르기
  • 배송 지역
  • 배송지 수
  • 예산 보유 여부
2

고객 분석

고객 조건과 Content Card의 태그를 비교합니다.

예시 입력
5월 · 40대 여성 · 100명 · 온라인 · 힐링 · 건강한 메뉴 선호 · 예산 미정
3

1차 메뉴 큐레이션

고객 상황에 따라 3개·5개·10개를 제안하고, 이 단계에서는 최종 견적이 아닌 예상 가격대만 제시합니다.

메뉴추천 이유수업시간예상 가격대
버섯덮밥과 오이고추된장무침건강한 한 끼 구성60분3만 원대
양배추쌈밥완성 화면과 건강 이미지가 좋음60분3만 원대
고사리 오일파스타익숙한 재료의 새로운 활용60분4만 원대
브리치즈 샐러드가볍고 감성적인 메뉴45분3만 원대
오이소박이제철성과 체험성이 높음60분3만 원대
4

방향 확정

고객이 메뉴 또는 방향을 선택합니다.

건강한 한식 방향가족 참여형2번과 4번 구체화예산에 맞는 2개 상세 제안
5

2차 상세 제안

과정개요서

  • 과정명과 교육 목적
  • 대상과 권장 연령
  • 진행 방식과 수업시간
  • 수업 내용과 진행 순서
  • 완성 메뉴와 참가자 준비물
  • 기대 효과

쿠킹박스 구성표

  • 식재료·소스·부재료
  • 레시피 카드
  • 포장·보관 형태
  • 참가자 준비 재료
  • 배송 일정

가격 및 운영조건

  • 재료원가·포장비·배송비
  • 강사비·운영비·콘텐츠비
  • 최소 인원
  • 1인 판매가와 총 견적
  • 추가 옵션

최종 산출물

  • 상세 제안서
  • 과정개요서
  • 쿠킹박스 구성표

  • 운영 일정표

09 · Build Plan

구축 단계

Phase 1. 구조 설계

  • 8개 핵심 Program 확정
  • 하위 Project 분류체계 확정
  • Content Card 항목 확정
  • 고객 문의 입력 항목 확정
  • 추천 태그와 점수 기준 확정

Phase 2. 기존 메뉴 데이터화

  • 현재 보유 메뉴 전체 등록
  • Program·Project·Season 연결
  • 상품 가능 여부 입력
  • 사진·영상·레시피 연결
  • 가격·배송·기업 추천 태그 입력

Phase 3. 운영·제안 체계

  • 월별 테마·메뉴 구성
  • 1차 메뉴 제안서 양식
  • 과정개요서·구성표
  • 가격 계산표·견적서
  • 몰·콘텐츠·SNS 캘린더
